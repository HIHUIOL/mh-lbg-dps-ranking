📐 计算公式与推导过程

以下为所有数值的完整推导，所有结果均可用此公式复现。不服可以自己按计算器。

一、基础帧数常量

开火帧数 F = 54 帧/枪
最快装填 R_fast = 54 帧
快速装填 R_quick = 84 帧

二、弹丸节约的数学本质（无穷级数）

每开一枪，有 p = 20% 概率不消耗子弹，且每次独立判定，可连续触发。

设弹夹容量为 C，则平均可射击次数为：

// 级数展开：
N = C + 0.2C + 0.04C + 0.008C + …
// 等比数列求和，首项 a₁ = C，公比 q = 0.2
N = C / (1 - 0.2) = C / 0.8 = 1.25C
等价于：每枪平均消耗 1 × 0.8 + 0 × 0.2 = 0.8 发，所以 C 发子弹平均能打 C ÷ 0.8 枪。

三、单个循环的总帧数

一个完整循环 = 打空弹夹 + 装填一次：

T_cycle = F × N + R
// F = 54 帧/枪，N = 平均射击数，R = 装填帧数

四、每枪平均帧数

F_avg = T_cycle / N = F + R / N

例如：最快装填 + 6发 + 无节约：

N = 6
T_cycle = 54 × 6 + 54 = 324 + 54 = 378 帧
F_avg = 378 / 6 = 63 帧/枪

五、DPS 计算公式

设单发伤害为 D（即你填的攻击力），游戏帧率按 60 帧/秒 计算：

// 每秒射击次数
Shots_per_sec = 60 / F_avg

// 每秒伤害
DPS = D × Shots_per_sec = D × 60 / F_avg

六、相对 DPS 与差距

设基准组合的 DPS 为 DPS_base：

相对DPS% = ( 该组合DPS / DPS_base ) × 100%

与基准差距 = 相对DPS% - 100%
例如：某组合相对DPS = 92.65%，则差距 = -7.35%，表示比基准低 7.35%。

七、完整算例（最快 + 7发 + 节约）

// 步骤1：平均射击数
N = 7 / 0.8 = 8.75 枪

// 步骤2：循环总帧数
T_cycle = 54 × 8.75 + 54 = 472.5 + 54 = 526.5 帧

// 步骤3：每枪平均帧
F_avg = 526.5 / 8.75 = 60.17 帧/枪

// 步骤4：假设攻击力 D = 300
DPS = 300 × 60 / 60.17 = 299.15

// 步骤5：若以自身为基准，相对DPS = 100%

八、全部 8 种组合的平均帧数速查

// 公式：F_avg = 54 + R / N，其中 N = C 或 C/0.8

① 最快 + 6发 + 无节约：N=6，R=54 → F_avg = 54 + 54/6 = 63.00
② 快速 + 6发 + 无节约：N=6，R=84 → F_avg = 54 + 84/6 = 68.00
③ 最快 + 7发 + 无节约：N=7，R=54 → F_avg = 54 + 54/7 ≈ 61.71
④ 快速 + 7发 + 无节约：N=7，R=84 → F_avg = 54 + 84/7 = 66.00
⑤ 最快 + 6发 + 节约：N=7.5，R=54 → F_avg = 54 + 54/7.5 = 61.20
⑥ 快速 + 6发 + 节约：N=7.5，R=84 → F_avg = 54 + 84/7.5 = 65.20
⑦ 最快 + 7发 + 节约：N=8.75，R=54 → F_avg = 54 + 54/8.75 ≈ 60.17
⑧ 快速 + 7发 + 节约：N=8.75，R=84 → F_avg = 54 + 84/8.75 = 63.60

九、注意事项

1. 本计算为纯打桩期望，不考虑走位、怪物动作、会心、肉质、距离补正、贯通判定次数等。
2. 单发伤害 = 你填写的攻击力，实际游戏还需乘动作值、肉质等系数，但相对排名不受影响（因为所有组合同乘一个系数）。
3. 弹丸节约按每次开枪独立判定处理，可连续触发，数学上等价于每枪消耗 0.8 发。
4. 帧率按 60 FPS 换算，若游戏实际帧率不同，绝对DPS会变，但相对排名不变。
